# திருக்குறள் குரல் செயலி (Thirukkural Voice-Only Assistant)

குரல் வழி மட்டுமே இயங்கும் முழுமையான தமிழ் திருக்குறள் மென்பொருள் செயலி (Voice-Only Tamil Assistant for Thirukkural).

இச்செயலியில் டாஷ்போர்டு, பட்டியல்கள், அட்டவணைகள் கிடையாது. சாளரத்தின் நடுவில் **ஒரே ஒரு பெரிய மைக் பொத்தான்** மட்டுமே இருக்கும். பொத்தானை அழுத்தி அல்லது விசைப்பலகையில் **Space** அழுத்தி தமிழில் பேசலாம். அனைத்து தகவல்களும் கணீர் குரலில் தமிழில் மட்டுமே பேசப்படும்.

---

## 🏛️ முக்கிய அம்சங்கள் (Key Features)

1. **ஒற்றை இடைமுகம் (Voice-First Minimal UI)**:
   - நடுவில் ஒரே ஒரு பெரிய வட்ட வடிவ மைக் பொத்தான்.
   - பொத்தானின் கீழே தற்போதைய குறளின் தமிழ் உரை மட்டும் சிறிய அளவில் தோன்றும்.
   - மவுஸ் கிளிக் அல்லது `Space` அழுத்தி உடனடியாக பேசலாம்.
   - பேசும்போதும் ஒலிக்கும்போதும் `Escape` அல்லது பொத்தானை மீண்டும் அழுத்துவதன் மூலம் உடனடியாக நிறுத்தலாம் (Barge-in Support).

2. **ஆஃப்லைன் தமிழ் குரல் அறிதல் (STT - Speech-to-Text)**:
   - `faster-whisper` (model: `small`, `language="ta"`), முற்றிலும் உள்ளூர் (local) மற்றும் இலவசம்.
   - VAD (Voice Activity Detection): பயனர் பேசி முடித்ததும் (மௌனம் நிலவியதும்) தானாகவே ஒலிப்பதிவை நிறுத்தி குறளைத் தேடுகிறது.
   - ஒலிப்பு மற்றும் எழுத்துப் பிழைகள் திருத்தம் (குறள்/குறல், அதிகாரம்/அதிகரம்/அடிகாரம், திருக்குறள்/திருகுறள்).
   - தமிழ் எண்கள், தமிழ் எண்குறியீடுகள் (௧௫௦), தமிழ் எண் சொற்கள் ("நூற்று ஐம்பது", "பன்னிரண்டு", "ஆயிரத்து முந்நூற்று முப்பது"), மற்றும் ஆங்கில எண்கள் ("one fifty") அனைத்தையும் துல்லியமாக எண்களாக மாற்றும் எண் பாகுபடுத்தி.

3. **இயற்கையான நரம்பியல் குரல் (TTS - Text-to-Speech)**:
   - Azure Neural Tamil Voice (`ta-IN-PallaviNeural` மற்றும் `ta-IN-ValluvarNeural`).
   - ரோபோட்டிக் ஒலி இல்லாத இனிய தமிழ் உச்சரிப்பு.
   - SSML மூலம் முதல் அடி மற்றும் இரண்டாம் அடிக்கு இடையே 450-550 மி.வி இடைநிறுத்தம் (pause), பொருளுக்கு முன் நீண்ட இடைநிறுத்தம்.
   - மீண்டும் மீண்டும் கேட்கப்படும் உரைகளுக்கான மின்னல் வேக ஆடியோ கேஷிங் (Audio Caching by text hash).

4. **உள்ளூர் தரவுத்தளம் (Offline SQLite Database)**:
   - 1330 குறள்கள், 133 அதிகாரங்கள் (ஒவ்வொரு அதிகாரத்திற்கும் சரியாக 10 குறள்கள்), 3 பால்கள் (அறத்துப்பால், பொருட்பால், காமத்துப்பால்).
   - துல்லியமான வேகமான தேடலுக்கு `rapidfuzz` அடிப்படையிலான தமிழ் உரைத் தேடல்.

## 🎙️ ஆதரிக்கப்படும் குரல் கட்டளைகள் (Supported Voice Queries)

| குரல் கட்டளை (Voice Utterance) | செயல்பாடு (Intent) | விளக்கம் |
|---|---|---|
| `"குறள் 150 சொல்லு"` | `kural_by_number` | 150-வது குறளைப் பாடி உரைக்கும் |
| `"நூற்று ஐம்பது சொல்லு"` / `"௧௫௦"` | `kural_by_number` | எண் சொற்கள் மற்றும் தமிழ் எண்குறியீடு |
| `"திருக்குறள் அதிகாரம் 12 சொல்லு"` | `adhikaram_by_number` | அதிகாரம் 12-ன் 10 குறள்களையும் 1.2 வினாடி இடைவெளியுடன் தொடர்ச்சியாகப் பாடும் |
| `"அகர முதல எழுத்தெல்லாம் சொல்லு"` | `kural_by_text` | முதல் சொற்களைக் கொண்டு குறள் 1-ஐக் கண்டறிந்து பாடும் |
| `"அறத்துப்பால் முதல் அதிகாரம் சொல்லு"` | `adhikaram_by_number` | அறத்துப்பாலின் முதல் அதிகாரம் (கடவுள் வாழ்த்து) |
| `"இதற்கு பொருள் சொல்லு"` | `meaning` | கடைசியாக ஒலித்த குறளின் தமிழ்ப் பொருளைக் கூறும் |
| `"அடுத்த குறள்"` / `"முந்தைய குறள்"` | `next` / `previous` | அடுத்த அல்லது முந்தைய குறளுக்குச் செல்லும் |
| `"மீண்டும் சொல்லு"` | `repeat` | தற்போதைய குறளை மீண்டும் ஒலிக்கும் |
| `"நிறுத்து"` / `"போதும்"` | `stop` | குரலை உடனடியாக நிறுத்தும் |
| `"அறத்துப்பால்"` / `"பொருட்பால்"` | `paal` | அந்தப் பாலில் உள்ள அதிகாரங்களை வரிசையாகக் கூறும் |

## 🚀 நிறுவுதல் மற்றும் இயக்குதல் (Installation & Running)

### 1. தேவைகளை நிறுவுதல் (Install Dependencies)
```powershell
# விர்ச்சுவல் சூழலை உருவாக்குதல்
python -m venv .venv
.\.venv\Scripts\activate

# தேவையான தொகுப்புகளை நிறுவுதல்
pip install -r requirements.txt
```

### 2. தரவுத்தளத்தை உருவாக்குதல் & சரிபார்த்தல் (Build Database)
```powershell
python data/build_db.py
```

### 3. செயலியை இயக்குதல் (Run Assistant)
```powershell
python app/ui.py
```
*சாளரம் திறந்ததும் "வணக்கம். பேச பொத்தானை அழுத்துங்கள்" என்ற வரவேற்புக் குரல் ஒலிக்கும். பெரிய நீல நிற மைக் பொத்தானை கிளிக் செய்து அல்லது Space அழுத்திப் பேசலாம்!*
